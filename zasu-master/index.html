FAQ

よくある質問

ZASU AUDIOとは？

ボーカルMIX、マスタリング、音源変換をブラウザで行える、ZASU WORKSのWebオーディオサービスです。

MIXでは何をしてくれますか？

ボーカルとインストの音量・バランス、EQ、歯擦音の抑制、コンプレッション、空間処理を調整します。AUTO BALANCEで声とオケの重なりを解析します。ピッチ補正・タイミング補正は行いません。両音源は同じ曲頭から書き出してください。

MASTERのSTANDARDとLOUDの違いは？

STANDARDは自然さとバランス、LOUDは音圧感と密度を重視します。まず30秒の無料試聴で仕上がりを確認してください。

対応ファイル形式は？

MIX：WAV / FLAC / AIFF / M4A / MP3。MASTER：WAV / FLAC。CONVERT入力：WAV / FLAC / AIFF / M4A（ALACなど）。CONVERT出力：WAV / FLAC / AIFF / ALAC / MP3。拡張子が対応していても、破損・特殊なコーデック等で処理できない場合があります。

最大ファイルサイズは？

MASTERは1ファイル500MB（500,000,000バイト）まで、MIXはボーカル・インストそれぞれ500MBまで、CONVERTは1ファイル500MBまでです。MASTERは最大500MBまでの音声ファイルに対応しています。大容量のファイルはアップロードや処理に時間がかかります。

どこまで無料ですか？購入すると何ができますか？

MIX / MASTERは処理後の音源を30秒無料で試聴できます。完成版は各¥500 / 1曲、MIX + MASTERは¥800 / 1曲です。購入後にフル尺処理を行い、完成音源をダウンロードできます。CONVERTは変換からダウンロードまで無料です。

処理した音源は保存されますか？

非公開ストレージに一時保存します。保存から24時間を経過した音源・結果ファイルを、1時間ごとの自動削除処理で順次削除します。完成後は早めにダウンロードしてください。詳しくはプライバシーポリシーをご確認ください。

ダウンロードできない場合は？

通信状態と保存期限を確認し、結果画面で再度お試しください。購入済みの場合は再購入せず、利用した機能・日時・エラー内容を添えてお問い合わせください。

返金できますか？

フル尺処理開始前はキャンセルのご相談を受け付けます。開始後の利用者都合による返金は原則対象外です。処理失敗、システム障害、重複決済は確認のうえ対応します。返金ポリシーをご確認ください。
